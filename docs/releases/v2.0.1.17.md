## Changes

- Prominent phase headings and clearer instructions for bidding and playing.
- Keep/discard confirmation shows both counts and explains that checked cards
  stay in the hand.
- Tapping anywhere during bot takeover resumes control, including on disabled
  cards. The same gesture cannot also submit a move; keyboard Resume remains.
- Updated Phoenix, Finch, other Hex dependencies, Python browser-test
  dependencies, esbuild, and Tailwind 3.4. No database schema changes.
