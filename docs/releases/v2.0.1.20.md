18:22:19 UTC with no games running.

## Second cause of the sign-in outage

After v2.0.1.18 fixed the Turnstile secret, password sign-in still failed
with "Please complete the verification challenge". The sign-in form is a
plain POST; LiveView unloads the page inside the submit event, destroying
every hook, and the Turnstile hook's `destroyed()` removed the widget and its
hidden `cf-turnstile-response` input before the browser read the form. The
server logged "Turnstile token missing from request". This had been the case
since Turnstile was added on 2026-08-04; the one session on 2026-08-17 came
from registration, which signs in with a post-auth token instead.

## Changes

- The hook removes the widget only after the submit, and only if LiveView
  took the element out of the page (`assets/js/turnstile_hook.mjs`, with unit
  tests).
- `python/auth_e2e.py` signs up, tries a wrong password, then signs in, and
  runs in the e2e workflow. It and the hook tests fail against the old hook.
