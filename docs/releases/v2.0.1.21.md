## Changes

- Turnstile is off in production unless `TURNSTILE_ENABLED=true`; the rate
  limits on sign-in, sign-up and email sends still apply. `.env` on the host
  now has `TURNSTILE_ENABLED=false` and keeps the working secret, so turning
  it on is that flag plus recreating `web` (see
  [deploy.md](../deploy.md#turnstile)).
- The live check accepts forms without a widget when Turnstile is off.
