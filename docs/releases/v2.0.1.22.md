# Release v2.0.1.22

Application commit: `61dd4dd`. Deployed on 2026-10-15 from 22:27:37 to
22:28:23 UTC, after the one game in progress ended.

## Changes

- `/healthz/auth` runs the Turnstile and Google checks in parallel, each cut
  off after 8s, so it always answers JSON. Failed checks are cached for 30s
  instead of 5 minutes.
- With Turnstile on, `turnstile_verifications` reports a rejected secret only
  after tokens from three client IPs were rejected since the last success.
- `TURNSTILE_ENABLED` accepts `true`/`1`/`yes`/`on` and `false`/`0`/`no`/`off`
  in any case and refuses to boot on any other value; a blank
  `TURNSTILE_SITE_KEY` keeps the configured one; the secret is trimmed.
- The Turnstile widget hook clears stale state on reset and re-render and
  reuses a widget still in a kept element.
- `python/live_check.py` detects Turnstile from the page when
  `/healthz/auth` does not answer.
