# Release v2.0.1.23

Application commit: `544e62b`. Deployed on 2026-10-24 from 17:25:23 to
17:25:58 UTC, after the one game in progress ended.

## Changes

- Google sign-ups, who get a random `player_xxxxxxx` name, are offered once
  to pick the name other players see. Visiting `/`, `/learn`, `/play` or a
  private lobby sends them to `/users/welcome` (never from `/game/:id`),
  which saves a name or keeps the generated one and returns them. Saving uses
  the settings rules: unique, banned-word screen, rename rate limit.
- New column `users.username_pending`. The migration set it for the 6 Google
  accounts (of 19) still on a generated name: ids 47–51 and 58. (The commit
  message says "6 of 15"; 19 is right.) Renaming in settings clears it too.
- Settings says the username is the name other players see.
