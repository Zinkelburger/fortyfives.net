# Release v2.0.1.24

Application commit: `85cdd88`. Deployed on 2026-10-24 from 17:51:16 to
17:51:28 UTC, with no games in progress.

## Changes

Security and maintenance only; no application changes.

- `bandit` 1.12.5 → 1.13.1 (CVE-2026-105659, HTTP/2 send-deadline reset,
  high; CVE-2026-105660, HTTP/1 authority sets `conn.host`, medium) and
  `plug_crypto` 2.2.0 → 2.2.1 (CVE-2026-105963, secret key base in stack
  traces). Other Hex deps updated within their constraints. These advisories
  had been failing CI's `mix hex.audit` step since v2.0.1.22.
- Erlang/OTP 27.3.4.13 → 27.3.4.19 (ERTS 15.2.7.9 → 15.2.7.14) and Elixir
  1.19.5 → 1.19.6. The builder is now `hexpm/elixir`, because the official
  `elixir:*-otp-27-alpine` images were last rebuilt in June and the 1.19.6
  tag has no amd64 image yet.
- Alpine 3.22 → 3.24.3 in both build and runtime stages (OpenSSL 3.5.9).
- CI-only: Pillow 12.3.0 → 13.0.0 (four CVEs) and the other Python test
  tools; three GitHub Actions bumped.
