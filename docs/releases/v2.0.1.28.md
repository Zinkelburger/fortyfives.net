# Release v2.0.1.28

Application commit: `4a754ee`. Deployed on 2026-11-09 from 16:31:51 to
16:32:04 UTC with no games in progress. v2.0.1.27 (`fd8cca8`) was built but
never deployed; this release contains it.

## Changes

- **Security advisories:** `ssl_verify_fun` 1.1.7 → 1.1.9 (critical:
  partial-label wildcard certificates matched across a label boundary),
  `ecto` 3.14.2 → 3.14.3 (high: unbounded query cache growth) and
  `phoenix_html` 4.3.0 → 4.4.0 (medium: attribute name injection; the
  `~> 4.3.0` pin had blocked it). `hackney` 4.10.0 also stops buffering one
  oversized chunk past `max_body_size`. `mix hex.audit`, which CI runs, had
  started failing on these after the last push. Security Audit now also runs
  every Monday at 09:00 UTC.
- **Toolchain:** Elixir 1.19.6 → 1.20.5, OTP 27 → 29.1.2, Alpine 3.24.4.
  `lksctp-tools` is installed so OTP 29 does not warn at every VM start.
- **Tailwind 3.4 → 4.3.5**, configured in `app.css` (the standalone binary
  cannot load a JS config; heroicons are in `assets/tailwind.heroicons.js`).
  Utilities stay outside a CSS layer: inside one, the site's element rules
  beat them, which broke headings and form labels in the first attempt. The
  UI check then showed 0 changed pixels on all 24 screenshots.
- **Return to the lobby after signing in.** On lobby pages the Register and
  Log in links carry `return_to`, so players come back to their lobby
  instead of the home page. On 2026-11-08 three friends ended up in three
  separate private lobbies after signing up mid-lobby; 7 visitors in 30 days
  left a private lobby for those pages.
- rrweb 2.1.5 → 2.2.2 (recorder and admin player), topbar 3.0.1, heroicons
  2.2.0, Python test packages, and other Hex updates.
- Host: nginx `1.30.6-alpine3.24` rebuilt image, certbot 5.8.0 → 5.9.0.
