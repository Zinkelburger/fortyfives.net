# Release v2.0.1.30

Application commit: `4b0fb30`. Deployed on 2026-11-10 from 17:56:42 to
17:56:45 UTC with no games in progress.

## Changes

- **Typed game state.** Phases are atoms listed in `Game.Phase` instead of
  strings, and the state is a `Game.State` struct with every field required.
  Nothing outside Elixir changed: `data-phase`, the event log and site events
  carry the same names (`Bidding` ... `Final Scoring`).
- **Quieter, more useful app log.** `GET /healthz` is no longer logged (the
  container healthcheck was about three quarters of the log). Account
  creation, email confirmation and change, password change and reset, Google
  linking and every `/admin` page view are logged by user id.
- **Host auditing and alerts** (applied to the host earlier the same day,
  not part of the image): auditd, audit records in journald, email alerts
  for logins from new addresses and for the daily host check, a daily copy
  of the journal to the laptop, and a 30-minute uptime check from GitHub.
  See "Auditing and alerts" in `deploy/contabo/README.md`.
