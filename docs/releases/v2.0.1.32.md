# Release v2.0.1.32

Application commit: `f959357`. Deployed on 2026-11-12 from 21:09 to
21:10:21 UTC with no games in progress.

## Changes

- **Analysis board at `/analysis`.** Play partners or cutthroat 2–6 against
  bots (site bot or the trained nets), with hints, a move list, takebacks,
  shareable links and a deal editor. Live tables are unchanged and keep the
  site bot. There is no nav button; the only link is "analysis board" in the
  home page's About paragraph.
- **Weights stay off GitHub.** The six `<variant>.bin` files from the private
  Frank-45s-Opus repo were copied by hand to `/data/analysis` in the
  `fortyfives_app_data` volume (owner `app`, mode 600). `docker-compose.yml`
  now sets `ANALYSIS_WEIGHTS_DIR: /data/analysis` on `web`. A variant
  without its file falls back to the heuristic bot.
- Cost: about 0.3–0.4 s of CPU per hand, with hints and every bot move
  (measured on a laptop).
