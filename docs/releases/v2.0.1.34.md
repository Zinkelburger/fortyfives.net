# Release v2.0.1.34

Application commit: `a7b406e`. Deployed on 2026-11-17 from 18:38:49 to
18:39:22 UTC with no games in progress: the last deploy that waited for
idle tables, since it moved the host to blue/green.

## Changes

- **Blue/green deploys.** Production runs `web-blue` and `web-green`
  behind nginx. A deploy starts the new image in the idle slot, checks it
  through nginx, and switches. Games on the old slot finish there; every
  other open page reloads onto the new slot, and players in the public
  queue or a private lobby are seated again with their bots. No 502 at the
  switch and no waiting for idle tables. `release.sh deploy` and `rollback`
  work this way; `release.sh restart` runs the live image again in the
  other slot (for `.env` changes). Containers are now
  `fortyfives-web-blue-1` / `fortyfives-web-green-1`, and responses carry
  `x-ff-slot`.
- **`deploy/contabo/test/run.sh`** rehearses two switches locally with
  browsers in a game, the queue and a lobby; the "Deploy rehearsal" workflow
  runs it.
- **plug 1.20.4** for EEF-CVE-2026-120287 (multipart length limit).
