# Release v2.0.1.35

Application commit: `79ad1f8`. Deployed on 2026-11-24: started 17:01:42,
live from 17:02:05, old slot stopped 17:02:18 UTC (blue/green).

## Changes

- **Private tables survive app switches.** Creating a table seats its
  creator. A dropped socket keeps the seat as away for three minutes, so a
  host can switch apps to send the link. Add a bot seats the player who
  taps it. Reopening the link of a table that already started goes straight
  into its game. When a lobby fills, a player already in another game is
  dropped from it, so nobody is dealt into two games.
- **Live table.** A turn clock (the hand panel's edge drains over the turn,
  and a pill counts the last 10 s), card faces preloaded per table, and the
  turn line as the headline during a hand (`.game-live` scopes these away
  from /analysis).
- **Budgets per network.** Bots: 30 per 10 min (was 6). Queue joins: 120
  per hour (was 40). The global bot cap (now 300) is only a backstop. Dev
  lifts both.
- **Analytics.** Meta's Messenger/Instagram link scanner no longer counts
  as a visitor. Lobby creators record `queue_join`. `/users/*` pages are
  noindex.
- **Dependencies** for four advisories: phoenix 1.8.17, phoenix_live_view
  1.2.15, idna 8.0.0 (with hackney 4.12.4), plus bcrypt_elixir 4.0.0,
  bandit 1.15.0 and smaller updates.
- **Deploys.** `slots.sh start` waits until nginx reaches the restarted
  slot before it returns. The rehearsal expects creators to be seated
  without Join. `fortyfives-quiet-reboot.timer` (host-only, installed
  2026-11-23) did its first reboot at 07:15 UTC today for kernel 6.8.0-149
  and libc6; the site was back in about 50 s.
